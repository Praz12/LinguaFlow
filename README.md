# LinguaFlow
Multi language learning app 

Core Features

Language selector with 10 languages (German, French, Spanish, Italian, Portuguese, Japanese, Mandarin, Korean, Arabic, Dutch)
Claude-powered conversations that adapt to your level
Chat mode (natural conversation) and Lesson mode (structured exercises)

Live Feedback Panel (right sidebar)

Color-coded feedback cards: 🟢 Positive, 🟡 Suggestions, 🔴 Corrections, 🔵 Info
Analyzes every message for grammar, vocabulary, and style
Tracks praise vs. correction counts

Left Sidebar — 3 tabs:

Goals — AI auto-generates personalized goals based on your patterns; add/check off your own
Progress — Skill bars for Grammar, Vocabulary & Fluency; stat cards; A1→C2 level pip tracker
Journal — Auto-generated session summaries every 5 messages
